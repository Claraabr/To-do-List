A to-do list app that helps you stay motivated and manage your time.
You can add tasks with an optional deadline, and the app shows how much
time is left for each one, so you always know what to do first.

- Add a task with the button or the Enter key
- Mark a task as done or not done
- Delete a task
- Tasks are saved in localStorage, so they stay after a reload
- Optional due date with a countdown ("2h 15m left", "Overdue")
- Filters: All, Forthcoming, Completed, Due in 24h, Overdue
- Progress bar to see how much of your list is done
